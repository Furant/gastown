# Local projects and IDE review implementation plan

User-approved scope: private local Git directories execute only on a paired node on the user's own computer, including when the control plane is remote. Tasks retain isolated local worktrees for human review, expose a bounded diff/file summary and explicit IDE opening, and never automatically commit, push, merge or create a PR.

## Contract and ownership

Server owns `console/server/**`. Add projects `repo_type` (default `remote`), `local_path`, `local_node_id`; nodes `local_device_hash`; one-use expiring pairing challenges. The browser stores a random device secret locally and sends `X-Local-Device` on authenticated requests. `POST /nodes/:id/pairing` requires owner and this header, returns `{code,expiresAt}`. On the actual computer `node node/index.mjs --config PATH --pair CODE` confirms through authenticated `POST /worker/pair {code}`. Codes expire after five minutes, are hashed at rest, single-use, and scope to node/owner/device. Node lists expose only `pairedToThisDevice` boolean, never the hash or device secret. Pairing is an explicit operator assertion of which machine is local, not hardware attestation; copying a node credential to another machine defeats device locality and is outside this trust boundary.

`POST /projects {name,repoType:'local',localPath,localNodeId,baseBranch,visibility:'private'}` requires this device's paired node owned by the user. Local projects never share. They are attached to their bound node's project grants transactionally so node-first onboarding is possible. Remote payloads retain existing behavior. Connection creation, task creation/approval/lifecycle/decomposition, worker claims, manual/automatic handoff, checkpoint export/upload/read and task visibility all enforce owner and bound node. Local approvals reject push or PR. Local tasks do not inherit connection sharing. Jobs include `{repoType:'local',localPath,localNodeId}`. Node polls require no browser header but must match the server binding. Browser operations require this device's pairing. Re-pairing cannot move a node with existing local projects to another device; revoke and explicitly recreate instead.

Node owns `console/node/**`. Add `--pair CODE`, `WorkerClient.pair()`. For local jobs require configured project mapping to realpath-match the declared local path, validate bound node ID when available, reject remote checkpoint/delivery authorization before spawning. Do not implicitly initialize repositories or modify original worktrees. On execution completion add result `localReview:{worktreePath,files:[{path,status}],diff,diffTruncated,filesTruncated}`: worktree path max2048, at most32 paths max240 each, textual diff max12000 characters and bounded UTF-8 bytes. Use Git commands without a shell and strip GIT_* inherited environment. Include tracked/staged/untracked file status, skip raw diff content for sensitive paths, binary and symlink content; never read arbitrary filesystem paths from task input. Summary comes from provider result; test results are not invented. Same-node continuation preserves worktree.

Frontend owns `console/web/**`. Generate persistent device secret, pairing action and local CLI instructions, local/remote project selector and own paired-node picker. Local directory defaults into downloadable node mapping. Filter connections and transfer/decomposition targets to the bound node and owner. Explain that local Git mapping must be configured before execution. Hide/reject push/PR approval for local projects. Task detail exposes top-level `localReview` only (list/result/events omit it) and displays local worktree, copy path, user-initiated Cursor deep link, changed files and escaped text diff for owner/paired browser only, with truncation markers. A task remains awaiting review.

Root owns `console/test/local-project.integration.test.mjs`, README and integration. Use temporary Git/PGlite and fixture tools only. Run scoped tests, then full coverage, syntax, audit and independent security review. Commit/push only the fork feature branch using the already authorized per-invocation ECC pre-push skip.
